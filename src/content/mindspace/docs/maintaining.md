# 维护公开版本

公开仓库保存模板、说明、提示词和教学示例，个人使用目录独立维护。

## 更新入口

- 修改工作方法：`docs/workflow.md`，同时核对 `template/WORKFLOW.md`。
- 修改起步模板：`template/`。
- 修改协作提示词：`prompts/`。
- 修改主题与描述：`site.json`；首页布局与主要文案在网站仓库中维护。
- 修改工具适配：`adapters.json`，核对官方文档；通用入口正文在 `prompts/connect.md`。
- 新增公开文件：显式加入 `site-manifest.json` 的 `files`；文档页同时加入 `pages`。

初始化只复制模板；已有个人空间不会被后续模板更新覆盖。升级时自行比较、按需合并，保留自己的内容。

## 网站同步

网站仓库与本仓库相邻时，运行网站的 `npm run sync:mindspace`。也可设置 `MINDSPACE_SOURCE` 指向本公开仓库。网站只接收清单中的文件，并生成完整下载包；不访问个人 Mindspace。

网站仓库提交同步后的快照，因此没有单独检出本仓库时仍能构建。远程公开仓库存在后，网站的现有定时构建会尝试读取 `main` 分支的最新公开内容；获取失败时明确使用网站已保存的快照，不生成空页面。

本仓库与网站的 Git 发布由维护者执行。更新模板仓库并不立即改变已部署网站，需等下一次网站构建成功。提交消息与身份遵守维护者的署名要求。

## 本地验证

```bash
python3 scripts/init.py /tmp/my-mindspace-check
```

首次应成功，重复执行应拒绝覆盖。检查生成目录的链接与占位符，再完成网站构建和桌面、移动端页面检查。
