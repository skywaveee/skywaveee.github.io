# 接入已有项目

将 `<MINDSPACE_PATH>` 换成个人空间的绝对路径（包含 HOME.md 的目录）。Codex、Cursor、ZCode Agent 写入项目根目录的 `AGENTS.md`；Claude Code 写入 `CLAUDE.md`。没有文件就新建，有则在末尾追加；同一个 Mindspace 入口只保留一份。详细适配见 [开始指南](../docs/getting-started.md)。

```text
## Mindspace

我的个人研究空间在 <MINDSPACE_PATH>。
每个新会话先读取该目录的 HOME.md 与 WORKFLOW.md，再按需读取 DAILY.md 当天条目和当前任务相关的项目、知识。
不要遍历全部个人记录。路径不存在或无访问权限时，明确报告，不能假装已读取。
已有知识库和实验代码留在原处，通过入口链接；使用材料前核对来源、证据和适用条件。
讨论后将论文细节写回共读笔记或原摘要，跨论文结论写入专题；稳定、明确的偏好再更新阅读规范。
个人理解只记录我实际表达的观点、疑问和验证经历，不把 AI 的阅读进度当成我的掌握程度。
我尚未读过的可靠材料也可以用于研究；在影响当前决策时，指出我最需要补的概念与原因。
有实质进展时更新相关记录，区分建议、实现、运行与验证；保留来源和重要修订依据。
遵守当前项目已有权限与发布规则，此入口不授予提交、上传或发布权限。
```
